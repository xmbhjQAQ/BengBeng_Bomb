# 绷绷炸弹 MVP

## Goal

交付一个无需账号、适合桌面与手机浏览器的临时会话式“绷住挑战”网站。发起者可以从 B 站视频创建一次性挑战并分享链接/图片；接收者在单页内完成隐私告知、摄像头校准、受控播放、本地笑脸检测和结算；发起者通过与公开挑战凭证严格分离的私密入口查看或销毁结果。

## Background and Confirmed Evidence

- 根目录当前没有产品应用或 Git 仓库；产品代码需要新建，不能以运行时方式引用后续会被删除的 `模块化开发及技术验证成果` 与 `已有后端`。
- `模块化开发及技术验证成果/B站视频+笑脸检测验证` 已验证 React 19、TypeScript、Vite、ArtPlayer、弹幕插件和 MediaPipe Tasks Vision 的组合，并已实现：
  - BV 视频页链接校验、解析服务客户端、封面防盗链处理、播放直链候选回退和弹幕加载；
  - 禁止用户播放、暂停、拖动和改速的播放器门控；
  - 摄像头、Face Landmarker、单人脸/姿态有效性判断、中性表情校准；
  - 基线归一化、指数平滑、危险阈值、持续时间失败阈值与恢复机制；
  - 丢脸宽限、暂停、稳定恢复、倒计时续播、缓冲和结算状态机；
  - 上述核心模块的单元/组件测试。
- `模块化开发及技术验证成果/B站外链解析后端` 与 `已有后端/API调用方法.md` 已提供 bilidirect 兼容接口：`/api/parse`、`/api/danmaku`、`/api/health`。视频直链有时效性，视频主体由浏览器直连 B 站 CDN，弹幕 XML 可经轻量服务转发。
- 已有后端 endpoint 和 Key 属于部署配置；Key 不得进入浏览器、分享凭证、仓库或文档。
- 当前 Cloudflare Workers 官方能力支持同一个 Worker 托管 SPA 静态资源、优先处理 `/api/*`、绑定 D1、使用 Secret，并通过 scheduled handler 定时清理过期数据。

## Functional Requirements

### R1 — Challenge creation

- 首页提供 B 站链接输入和解析反馈，支持直接 BV 视频页链接；短链应给出明确、可操作的错误，除非后端能够安全解析跳转。
- 展示解析得到的视频标题、封面、简介、稳定标识、时长等信息；临时播放直链不得写入挑战凭证。
- 发起者填写必需的昵称、可选的接收者昵称和短留言，所有字段有明确长度限制、计数与校验。
- 服务端签发带版本、来源、BVID/CID/分 P、发起者、接收者、留言、创建/过期时间、nonce 和模式配置的公开 Challenge 凭证，并用 HMAC 防篡改。
- 同时返回完全独立的私密 Result/Manage Token；公开凭证中不得出现管理 Token、结果查询密钥、上游 API Key、Secret 或 B 站临时直链。
- 创建后展示可复制的公开链接、仅供发起者保存的私密结果入口，以及浏览器本地生成的分享图片。分享图片含封面、标题、简短简介、昵称/留言、有效期提示和公开挑战二维码，可下载或调用系统分享。
- 创建阶段不写入 D1；未被打开的挑战不产生长期状态。

### R2 — Single-page recipient flow

- 打开公开链接后验证签名和有效期，并在需要播放时通过后端重新解析 B 站直链。
- 同一 SPA 视图连续经历介绍、隐私说明、授权、前置检测、校准成功、预加载待开始、沉浸挑战、丢脸恢复和结算，不使用整页刷新打断流程。
- 首屏明确说明：摄像头画面只在浏览器本地检测，不上传、不保存、不做人脸身份识别；挑战结果及失败时间会返回发起者；匿名结果可能计入公共聚合统计。
- 只有用户主动接受挑战后才请求摄像头权限；权限拒绝、无摄像头、模型加载失败和浏览器不兼容均有可恢复说明。
- 校准要求稳定单人脸和中性表情，成功后给出明确反馈，用户再次主动点击才开始挑战。

### R3 — Controlled challenge playback

- 正式开始前播放器已加载但暂停；开始后进入原生全屏或移动端兼容的沉浸式替代布局。
- 挑战期间禁止用户暂停、播放、seek、拖动进度、改变倍速、画中画等破坏规则的操作，只保留音量和弹幕开关。
- 右上角显示本地摄像头气泡和人脸范围反馈，左上角显示“绷住 / 危险 / 没绷住”。
- 人脸缺失、多脸、严重偏转、遮挡或低置信度不直接判失败；超过短暂宽限后立即暂停，稳定恢复后约 3 秒倒计时再继续。
- 页面失焦、视频错误、异常 seek/暂停/倍速等规则破坏应使本轮无效并给出重新开始入口，不应错误记录为“没绷住”。
- 笑脸判定复用并产品化现有基线校准、连续分数、时间平滑、持续阈值和回落恢复机制；摄像头帧与逐帧表情数据永不上传。
- 最终失败时读取播放器真实 `currentTime`、立即停止并进入结算；视频正常播完且未失败则记录成功。

### R4 — Sessions, results and lifecycle

- 首次真实打开或开始挑战时才在 D1 创建临时记录；一次挑战只接受一个有效完成结果，完成接口必须幂等。
- 一次挑战只产生少量 API 请求：解析/打开、开始、完成；禁止上传高频 Smile Score，结果页不高频轮询。
- 完成结果仅包含完成状态、失败时间/坚持时间、必要的客户端版本与非生物识别诊断；不保存摄像头帧、面部特征、逐帧分数或身份信息。
- 私密结果入口可查看是否打开、是否开始、是否完成、结果、失败秒数和过期时间，并可主动销毁私密记录。
- 使用 D1 scheduled cleanup 清除过期挑战/结果；Secret 仅通过 Cloudflare Secret/环境变量提供。
- 生命周期由服务端非敏感配置集中控制：默认 `CHALLENGE_TTL_HOURS=48`，完成后的私密结果默认 `RESULT_TTL_HOURS=48`；修改配置不要求修改业务代码或前端构建。

### R5 — Settlement, public report and aggregation

- 成功与失败使用一致的结算结构，展示视频信息、个人结果和匿名聚合数据：总次数、成功/失败人数、失败率、平均坚持时间、主要失败时间点、分布/热力图。
- 完成后服务端可签发不含管理能力的公开报告凭证；结算页支持公开报告链接和浏览器本地生成的报告图片/二维码。
- “转发此挑战给朋友”返回制作状态并预填当前视频，只要求重新填写昵称、接收者和留言，生成新的独立 Challenge。
- 匿名视频聚合只保存不可反查到昵称、留言或管理入口的计数/时间桶，不引入账号或社交关系。

### R6 — Configuration, quality and deployment

- 产品代码模块化拆分前端视图、状态机、摄像头、检测器、评分、播放器、API 客户端、Worker 路由、签名、数据访问与分享图生成，不堆积到单文件。
- 非敏感配置集中管理：API 路由、默认时效、文本长度、播放清晰度、检测阈值、校准参数、恢复时间、统计桶等；敏感配置全部由 Worker Env/Secret 提供。
- 提供 D1 migrations、Wrangler 配置模板、`.dev.vars.example`、部署说明和隐私/使用限制说明，不提交真实 endpoint Key、Cookie 或 Secret。
- 复用的参考代码和 MediaPipe 模型/WASM/许可证复制到产品目录后独立工作；删除两个参考目录后，构建、测试和运行仍成功。
- 对签名/防篡改、Token 分离、过期、幂等完成、数据销毁、状态机、评分、输入校验、分享链接和主要组件流程提供自动化测试。

## Acceptance Criteria

- [ ] AC1：从直接 B 站 BV 视频链接可解析并展示标题、封面、简介与时长，浏览器播放流量直接访问 B 站 CDN；过期直链在播放前重新解析。
- [ ] AC2：生成挑战不会写 D1，返回可用的公开链接、私密结果入口和含公开二维码的可下载分享图片；公开凭证经篡改、过期或格式错误时被拒绝。
- [ ] AC3：检查公开凭证、分享图片/二维码和前端产物，均不包含管理 Token、API Key、Cloudflare Secret、Cookie 或临时视频直链。
- [ ] AC4：摄像头只在主动接受后请求；网络面板与测试证明无图像、landmark、blendshape 或逐帧评分上传。
- [ ] AC5：校准、待开始、受控播放、危险/失败、丢脸暂停与稳定倒计时恢复、成功/失败结算均在同一 SPA 内可完成。
- [ ] AC6：挑战期间用户无法通过可见控件、视频点击、进度条、键盘或脚本触发的普通媒体事件暂停、seek 或改速；异常行为不会被记成笑失败。
- [ ] AC7：失败记录播放器真实秒数；成功记录完整播放；完成提交幂等且每个 Challenge 只接受一个有效结果。
- [ ] AC8：私密入口与公开挑战/报告凭证不可互换，可查看状态并销毁结果；过期记录可由定时任务清除。
- [ ] AC9：结算页展示匿名聚合统计与时间分布，能生成不带管理能力的报告链接和本地报告图片。
- [ ] AC10：从结算返回制作状态时视频已预填，生成的是 nonce 不同的新 Challenge。
- [ ] AC11：桌面 Chromium 与主流移动端浏览器具备响应式布局；不支持原生全屏时仍有沉浸式替代；摄像头/自动播放限制有明确处理。
- [ ] AC12：`type-check`、lint、单元/组件测试、Worker 集成测试和生产构建通过；产品不依赖两个参考目录且部署文档可复现本地 D1 与 Cloudflare 部署。

## Out of Scope

- 登录、注册、账号、用户中心、历史挑战、好友关系、排行榜身份体系或永久私人记录。
- 服务端人脸识别、摄像头上传/存储、逐帧 Smile Score 上传或人工查看摄像头。
- 代理 B 站视频主体流量、保存视频文件或为每张分享图建立服务端图片存储。
- 实时结果轮询、聊天、通知推送、重社区或商业化系统。
- 第一阶段保证所有 B 站短链/QQ 小程序分享格式均可解析；可安全支持的格式之外应明确提示用户粘贴 BV 视频页链接。
- 自动执行真实 Cloudflare 生产部署、创建线上 D1 或写入用户账户 Secret；交付部署就绪代码与命令，由用户提供账户授权后执行。

## Key Product Decisions

- 未完成挑战默认在创建后 48 小时失效。
- 挑战完成后的私密结果默认额外保留 48 小时（2 天）。
- 两个时效均由服务端非敏感配置控制，可按部署环境修改。
- 主动销毁或到期后删除私人挑战/结果记录，但已经脱敏且无法关联个人的匿名聚合贡献继续保留。
